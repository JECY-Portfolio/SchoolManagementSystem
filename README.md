School Management System
A C# console-based application for managing students, teachers, courses, enrollments, and grades.

Features
Add and manage students, teachers, and courses

Enroll students in courses

Assign teachers to courses

Record and display grades

Input validation and clean console output

Getting Started
Prerequisites
Visual Studio or any C# compatible IDE

Run the application via the terminal or IDE.

Usage
Use the console to interact with the system.

Follow the on-screen instructions to add students, teachers, courses, enroll students, assign teachers, and input grades.
